# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text at that link is the code of conduct for this project.

## Our pledge

We as members, contributors, and leaders pledge to make participation in our
community a harassment-free experience for everyone, regardless of age, body
size, visible or invisible disability, ethnicity, sex characteristics, gender
identity and expression, level of experience, education, socio-economic status,
nationality, personal appearance, race, caste, color, religion, or sexual
identity and orientation.

In short: be respectful, assume good faith, give and accept constructive
feedback, and focus on what is best for the community. Harassment, insults,
sexualized language or imagery, publishing others' private information, and
other conduct that would be inappropriate in a professional setting are not
accepted.

## Scope

This code of conduct applies in all project spaces (issues, pull requests,
discussions) and when someone officially represents the project elsewhere.

## Reporting

Report unacceptable behavior privately to the maintainer by opening a
[private security advisory](../../security/advisories/new) on this repository
and stating that it is a code of conduct report. All reports are reviewed
promptly and handled confidentially.

## Enforcement

The maintainer may remove, edit, or reject contributions that do not follow
this code of conduct, and may warn, temporarily ban, or permanently ban
contributors, following the enforcement guidelines of the Contributor Covenant
2.1.
