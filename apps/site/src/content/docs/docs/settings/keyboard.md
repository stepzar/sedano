| Shortcut | Action |
|---|---|
| `⌘K` | jump to a workspace, session or action |
| `⌘D` | new agent tab, with the inline launchpad |
| `⌘T` | new terminal tab on the machine you are looking at |
| `⌘W` | close the current tab |
| `⌘1` … `⌘9` | jump to that tab in the strip |
| `⌘B` | show or hide the sidebar |
| `⌘,` | settings |
| `⌘+` / `⌘−` | conversation text size |
| `⌥⌘+` / `⌥⌘−` | interface text size |
| `esc` | close the overlay, or interrupt the running turn |

A new agent tab is not a dialog: `⌘D` adds a tab with one text field and a chip
for each setting (workspace, harness, model, effort, approvals). The tab is
named after your first message; a terminal tab is named after what it runs.

Shortcuts cannot be remapped today.
