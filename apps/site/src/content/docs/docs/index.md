Sedano is a macOS app that runs coding-agent CLIs (Claude Code, Codex, Gemini
CLI, Grok, opencode, Command Code, Freebuff) and terminal tabs side by side, on
this Mac or on SSH hosts you enable. These pages describe what it does today,
including what it does not do.
